# Варианты цветных значков командной панели

Стиль выбирается в ⚙ → «Значки» и сохраняется в настройках (`ui.iconStyle`: `Outline` / `Duotone` / `Plate`).
Все значки рисует `Controls/ToolIcon`: стиль наследуется от окна. Форма значков у всех трёх одна и та же
(геометрия 16×16 в `MainWindow.axaml`), различается только окраска.

## Цвета по смыслу кнопки

| Кнопка | Ключ кисти | Светлая тема | Тёмная тема |
|---|---|---|---|
| Добавить | `IconAddBrush` | `#639922` | `#97C459` |
| Удалить | `IconDeleteBrush` | `#E24B4A` | `#F09595` |
| Дерево / Список | `IconViewBrush` | `#378ADD` | `#85B7EB` |
| Развернуть / Свернуть все | `IconFolderBrush` | `#BA7517` | `#EF9F27` |
| Обновить | `IconRefreshBrush` | `#1D9E75` | `#5DCAA5` |
| Тема: авто | `IconAutoThemeBrush` | `#5F5E5A` | `#B4B2A9` |
| Тема: светлая | `IconLightThemeBrush` | `#BA7517` | `#EF9F27` |
| Тема: тёмная | `IconDarkThemeBrush` | `#7F77DD` | `#AFA9EC` |
| Настройки | `IconSettingsBrush` | `#5F5E5A` | `#B4B2A9` |
| Дерево: папка | `IconFolderBrush` | `#BA7517` | `#EF9F27` |
| Дерево: «Недавние» (часы) | `IconRecentBrush` | `#378ADD` | `#85B7EB` |
| Избранное: папка и звезда у базы | `IconFavoriteBrush` | `#E0900F` | `#FAC775` |

Кисти заданы в `LauncherApplication.axaml` (ThemeDictionaries), так что меняются вместе с темой.
Недоступная кнопка (например, «Удалить» без выбранной базы) показывает значок полупрозрачным.

## A. Цветной контур (`Outline`, по умолчанию)

Линия значка окрашена кистью кнопки, фон кнопки прежний.

## B. Двухтоновый (`Duotone`)

- Контур — цвет текста кнопки (`$parent[Button].Foreground`), толщина 1.3.
- Под контуром — заливка той же кистью с прозрачностью 0.5 (на сером фоне кнопки 0.35 почти не видно):
  - Добавить — круг r=6.5 под плюсом;
  - Удалить — тело корзины `M3.6,4 L4.5,14.5 L11.5,14.5 L12.4,4 Z`;
  - Дерево / Список — полосы под строками (прямоугольники высотой ≈3.4);
  - Развернуть / Свернуть — передняя папка `M1.5,4.5 L11.5,4.5 L11.5,14.5 L1.5,14.5 Z`;
  - Обновить — круг r=5.5 под стрелкой;
  - Солнце — круг r=3, месяц — весь серп, шестерёнка — круг r=4.5;
  - Авто — закрашенная половина круга сплошной серой кистью.

## C. Цветная плашка (`Plate`)

- Квадрат 16×16 со скруглением 3.5, залит кистью кнопки.
- Знак уменьшен до 0.72 и центрирован; линии утолщены, чтобы не стать тоньше, чем в других стилях.
- Цвет знака — белый на насыщенной плашке, почти чёрный (`#1F1F1F`) на светлой: у кистей тёмной темы яркость выше 0.55.
- Самый заметный вариант; на панели из многих кнопок пестрит — возможно, только для «Добавить».
