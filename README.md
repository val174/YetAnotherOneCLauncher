# YetAnotherOneCLauncher

Лаунчер информационных баз 1С:Предприятия 8, альтернатива штатному окну запуска (`1cestart`). Работает с теми же списками баз, что и стартер 1С, поэтому переходить можно в обе стороны: базы, добавленные в лаунчере, видны в стартере, и наоборот.

Возможности:
- поиск по базам в любой раскладке;
- избранное и недавние базы;
- дерево групп или плоский список;
- параметры запуска у базы и у группы, сохранённые пароли;
- выбор версии и разрядности платформы;
- очистка кэша;
- проверка доступности баз.

Разработчикам: устройство проекта, сборка и принятые решения описаны в [AGENTS.md](AGENTS.md), план работ — в [docs/ROADMAP.md](docs/ROADMAP.md).

## Установка и запуск

Лаунчер — один файл `YetAnotherOneCLauncher.exe`, установка и .NET не нужны. Его можно положить в любой каталог и запускать оттуда.

Первый запуск дольше следующих: лаунчер распаковывает свои библиотеки во временный каталог.

Лаунчер ничего не хранит рядом с exe. Его данные лежат в каталоге настроек пользователя: `%APPDATA%\YetAnotherOneCLauncher` в Windows и `~/.config/YetAnotherOneCLauncher` в Linux. Подробнее — в разделе «Где хранятся данные».

## Главное окно

**Панель кнопок** (слева направо):
- дерево или список;
- развернуть и свернуть все группы;
- добавить базу или группу;
- удалить;
- «Все базы»;
- «Недавние»;
- обновить списки;
- тема (как в системе, светлая, тёмная);
- настройки.

Справа от кнопок — поле поиска.

**Список баз.** В дереве базы разложены по группам, как в стартере 1С. Сверху — группа «Избранное». Колонки:
- наименование;
- платформа, на которой база запустится (оранжевым, если нужной версии нет);
- режим запуска;
- дата последнего запуска.

Порядок в дереве — по наименованию или свой. Переключается щелчком по заголовку «Наименование». Если переставить базы, пока включён порядок по наименованию, лаунчер запишет этот порядок в список и переключится на свой. Одну группу можно упорядочить по наименованию из контекстного меню.

**Недавние.** Кнопка с часами показывает только базы, которые запускались из лаунчера, свежие сверху. Поиск ищет среди них. Добавлять, удалять и переставлять базы в этом режиме нельзя. Кнопка «Все базы» возвращает полный список.

**Поиск** начинается с любого набора текста, даже если фокус в списке. Ищет:
- по имени, серверу, пути и адресу базы;
- в любой раскладке (`,e[ufknthbz` найдёт «Бухгалтерия»);
- по начальным буквам слов («зуп» найдёт «Зарплата и управление персоналом»).

Сначала идут более точные совпадения. Esc очищает поиск.

**Справа — кнопки запуска и свойства базы.**

Кнопки «1С: Предприятие» и «Конфигуратор» видны всегда. У каждой справа прикреплена кнопка «Запустить с параметрами».

Под кнопками — «Свойства информационной базы»: имя, кнопка «В избранное» и три группы свойств:
1. Тип, Клиент, Платформа, Параметры, Пользователь, Подключение. У подключения есть кнопки «Копировать строку подключения» и «Открыть каталог базы» (для файловых баз).
2. Источник (в каком списке найдена база) и Группа.
3. Кэш, Доступность, Последний запуск, Запусков.

Панель свойств скрывается кнопкой в правом углу строки состояния или флажком в настройках. Ширина правой колонки меняется перетаскиванием разделителя.

**Строка состояния** (слева направо):
- адрес выделенной базы и кнопка его копирования;
- сообщения лаунчера;
- число недоступных баз (⚠);
- размер кэша (кнопка открывает окно «Кэш баз»);
- число найденных платформ.

## Запуск баз

- **1С: Предприятие** — двойной щелчок, Enter или F3. **Конфигуратор** — F4 или контекстное меню. Веб-базы открываются в браузере.
- **Запустить с параметрами** (F6) — разовый запуск. Можно указать параметры командной строки, пользователя, клиент и версию платформы. Версию можно запомнить для базы.
- **Версия платформы** берётся из свойства `Version` базы. Если его нет — из версии по умолчанию стартера 1С. Если нет и её — самая новая установленная. Если нужной версии нет, лаунчер не запускает другую молча, а спрашивает и предлагает ближайшую из той же ветки.
- **Разрядность** задаётся в свойствах базы, поле «Разрядность»:
  - только 32 или только 64 бита;
  - предпочтительно 32 или 64;
  - автоматически.

  Хранится так же, как у стартера 1С. Если не задана, берётся разрядность из настроек лаунчера.
- **Параметры запуска** есть у базы и у группы; параметры группы действуют на все базы в ней. При запуске они применяются по порядку:
  1. параметры из списка баз (`AdditionalParameters`);
  2. параметры групп, от верхней к вложенной;
  3. параметры базы;
  4. разовые параметры.
- **Пользователь и пароль** базы задаются в «Параметрах запуска…». Пароль хранится в хранилище паролей ОС: в Windows — «Диспетчер учётных данных», в Linux — связка ключей. В логах и на экране он скрыт. Если пароль прочитать не удалось, 1С спросит его сама.

## Свои шаблоны параметров

В окне «Параметры запуска» можно вставить параметр из списка шаблонов. Список настраивается в меню «Настройки» → «Свои шаблоны параметров…».

Окно показывает таблицу известных параметров командной строки 1С с описаниями: сверху свои (с меткой «свой»), ниже встроенные.

Параметры в окне пишутся без «/». Лаунчер подставляет его сам, когда шаблон выбирают для запуска: `N Иванов` превратится в `/N Иванов`.

- **Добавить:** введите параметр и описание в поля под таблицей и нажмите «Добавить» или Enter.
- **Изменить:** выделите свой параметр и нажмите «Изменить», F2 или сделайте двойной щелчок. Enter применяет изменение, Esc отменяет.
- **Удалить:** кнопка «Удалить» или Del. Встроенные параметры не изменяются и не удаляются.
- Изменения сохраняются кнопкой «Сохранить».

## Список баз

Лаунчер читает те же файлы, что и стартер 1С:
- личный список `ibases.v8i`;
- общие списки из `1cestart.cfg`;
- списки с веб-сервиса.

Если общий список или веб-сервис недоступен, его базы показываются из последней удачной копии с датой.

Правится только личный список. Можно:
- добавлять, изменять, удалять и копировать базы;
- создавать и переименовывать группы;
- менять порядок, в том числе перетаскиванием;
- загружать и выгружать `.v8i`.

Удаление убирает базу только из списка, сама база остаётся на месте.

Лаунчер не теряет чужих изменений в файле. Если стартер 1С или другая программа изменили список, он перечитывается автоматически. При первой записи за сеанс сохраняется резервная копия `ibases.v8i.bak`.

## Кэш баз

В свойствах базы показан размер её кэша. Окно «Кэш баз» открывается кнопкой с размером кэша в строке состояния. В нём:
- кэш всех баз;
- кэш баз, которых уже нет в списках;
- очистка выбранного.

Кэш удаляется насовсем, без корзины. Кэш базы, которая сейчас открыта, не трогается. «Очистить кэш и запустить» есть в контекстном меню.

## Проверка доступности баз

Лаунчер в фоне проверяет, можно ли дотянуться до каждой базы. Цель — заранее увидеть, что каталог базы пропал или сервер выключен, а не ждать ошибки от 1С. Проверка включена по умолчанию и выключается флажком «Проверять доступность баз» в настройках.

### Когда проверяется

- после каждой полной загрузки списков: при открытии лаунчера, по кнопке «Обновить» (F5) и когда списки перечитываются из-за изменений в `1cestart.cfg`;
- сразу после включения флажка в настройках.

Проверка идёт в фоне и не мешает работать: список показывается сразу, отметки появляются, когда проверка закончится.

База, которую только что добавили или изменили в лаунчере, проверяется при следующей полной загрузке (F5).

Результаты не сохраняются между запусками лаунчера.

### Что проверяется

Способ зависит от типа подключения базы:

| Тип базы | Строка подключения | Что делает лаунчер | Когда база считается доступной |
|---|---|---|---|
| Файловая | `File="C:\Bases\Buh"` | проверяет, что каталог базы существует | каталог найден |
| Клиент-серверная | `Srvr="srv1c";Ref="buh"` | открывает TCP-соединение с менеджером кластера 1С и сразу закрывает его | сервер принял соединение |
| Веб-база | `ws="https://web/buh"` | открывает TCP-соединение с веб-сервером и сразу закрывает его | веб-сервер принял соединение |

Как определяется адрес:
- **Порт сервера 1С.** Если он указан в `Srvr` (`srv1c:1641`), берётся он, иначе стандартный порт менеджера кластера 1541. Понимаются записи вида `tcp://srv1c:1541` и IPv6 в квадратных скобках (`[::1]:1541`). Если в `Srvr` перечислено несколько серверов через запятую или точку с запятой, проверяется первый.
- **Порт веб-сервера** берётся из адреса, а если его там нет — стандартный: 80 для `http`, 443 для `https`.

Чего проверка **не** делает — это цена быстроты и отсутствия побочных эффектов:
- не открывает базу, не входит в неё и не проверяет имя пользователя и пароль;
- у файловой базы не проверяет файл `1Cv8.1CD` и права на запись. Проверяется только, что каталог виден;
- у серверной базы не проверяет, что в кластере есть база с именем из `Ref`, и не проверяет рабочие процессы и их порты. Проверяется только, что менеджер кластера принимает соединения;
- у веб-базы не отправляет HTTP-запрос. Проверяется только, что веб-сервер принимает соединения, а не что публикация по этому пути существует.

Поэтому отметка «доступна» означает только, что адрес отвечает. Отметка «недоступна» почти наверняка означает, что запуск не удастся: каталога нет, сервер выключен, адрес неверен или соединение закрыто сетевым экраном.

### Ограничения по времени и нагрузке

- На каждую проверку даётся **3 секунды**. Не ответил за это время — считается недоступным («нет ответа за 3 с»). Это защищает и от «зависших» сетевых путей, на которых проверка каталога может ждать очень долго.
- Одновременно выполняется не больше **8** проверок.
- Одинаковые адреса проверяются **один раз**. Если на одном сервере 1С двадцать баз, к менеджеру кластера будет одно подключение. Одна и та же база из нескольких списков тоже проверяется один раз.
- Если строку подключения не удалось разобрать (нет пути, сервера или адреса), база не проверяется и помечается «проверить нельзя».

### Как показывается результат

- В дереве и списке перед именем недоступной базы стоит ⚠. Подсказка к значку объясняет причину.
- В свойствах базы, строка «Доступность», показано одно из значений:
  - «доступна (srv1c:1541 отвечает)»;
  - «недоступна: каталог базы не найден: …»;
  - «недоступна: srv1c: нет ответа за 3 с»;
  - «проверить нельзя»;
  - «не проверялась».
- В строке состояния — «⚠ недоступно: N», если такие базы есть.
- В лог пишется итог: сколько баз проверено и сколько не отвечает.

Отметка ничего не запрещает: недоступную базу можно запустить, и 1С сама сообщит, что не так. Если выключить проверку, отметки сразу снимаются, и лаунчер перестаёт обращаться к сети ради неё.

## Настройки

Кнопка с шестерёнкой:

| Настройка | Что делает |
|---|---|
| Тема | как в системе, светлая или тёмная (то же переключает кнопка темы на панели) |
| Стиль значков | «Стиль 1» — цветной контур, «Стиль 2» — знак на цветной плашке |
| После запуска базы | ничего не делать, свернуть окно или закрыть лаунчер |
| Сворачивать в трей | свёрнутое окно убирается с панели задач. Значок лаунчера — в области уведомлений: щелчок возвращает окно, в меню есть «Открыть лаунчер» и «Выход» |
| Запретить повторный запуск | второй запуск лаунчера не открывает новое окно, а показывает уже работающее, в том числе из трея |
| Файловые базы с клиентом «Автоматически» открывать в толстом клиенте | для баз, у которых клиент не выбран явно |
| Свойства информационной базы | показать или скрыть панель свойств |
| Проверять доступность баз | фоновая проверка (см. выше) |
| Свои шаблоны параметров… | окно своих шаблонов |
| О программе… | версия, автор, сведения о среде |

Настройки сохраняются сразу. «Запретить повторный запуск» начинает действовать со следующего запуска лаунчера.

## Клавиши

| Клавиши | Действие |
|---|---|
| набор текста | поиск |
| F3, Enter, двойной щелчок | запуск в режиме 1С: Предприятие |
| F4 | Конфигуратор |
| F6 | запустить с параметрами |
| ↓ | из поиска — к списку |
| Esc, Ctrl+Q | очистить поиск |
| Ctrl+F | к полю поиска |
| Ctrl+D | в избранное / из избранного |
| F5 | перечитать списки и платформы |
| Ctrl+N, Ins | новая база |
| Ctrl+Shift+N | новая группа |
| F2 | изменить базу, переименовать группу |
| Del | удалить из списка (сама база не удаляется) |
| Alt+↑, Alt+↓ | порядок в группе |

В Windows у значка лаунчера на панели задач есть список переходов (правый щелчок) с пятью последними базами. Щелчок по базе запускает её, даже если лаунчер закрыт.

## Где хранятся данные

| Что | Где |
|---|---|
| Списки баз | там же, где у стартера 1С: `%APPDATA%\1C\1CEStart\ibases.v8i` и `1cestart.cfg` |
| Настройки лаунчера: избранное, история, параметры запуска, вид окна | `<каталог настроек>\settings.json` |
| Копии общих списков и списков с веб-сервиса | `<каталог настроек>\list-cache` |
| Лог | `<каталог настроек>\logs\launcher-<дата>.log`, хранится 14 дней |
| Пароли | хранилище паролей ОС, в `settings.json` их нет |

`<каталог настроек>`: `%APPDATA%\YetAnotherOneCLauncher` в Windows и `~/.config/YetAnotherOneCLauncher` в Linux.

Лаунчер хранит свои настройки отдельно и не пишет их в списки баз 1С.
