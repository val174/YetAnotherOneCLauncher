# YetAnotherOneCLauncher

Лаунчер информационных баз 1С:Предприятия 8, альтернатива штатному окну запуска (`1cestart`). Работает с теми же списками баз, что и стартер 1С, поэтому переходить можно в обе стороны: базы, добавленные в лаунчере, видны в стартере, и наоборот.

Возможности:
- поиск по базам в любой раскладке;
- избранное и недавние базы;
- дерево групп или плоский список;
- параметры запуска у базы и у группы, сохранённые пароли;
- выбор версии и разрядности платформы;
- очистка кэша;
- проверка доступности баз.

Разработчикам: устройство проекта, сборка и принятые решения описаны в [AGENTS.md](AGENTS.md), план работ — в [docs/ROADMAP.md](docs/ROADMAP.md).

## Установка и запуск

Лаунчер — один файл: `YetAnotherOneCLauncher.exe` для Windows x64 или `YetAnotherOneCLauncher` для Linux x64 (около 63 МБ). Установка и .NET не нужны. Файл можно положить в любой каталог и запускать оттуда; в Linux ему нужно право на выполнение (`chmod +x YetAnotherOneCLauncher`).

Обычно окно со списком баз открывается за 1–2 секунды. Первый запуск новой версии дольше (до 7–8 с): лаунчер распаковывает свои библиотеки во временный каталог. Общие списки с сетевых ресурсов дочитываются в фоне — если ресурс не отвечает, это не задерживает ни окно, ни запуск баз.

Лаунчер ничего не хранит рядом с exe. Его данные лежат в каталоге настроек пользователя: `%APPDATA%\YetAnotherOneCLauncher` в Windows и `~/.config/YetAnotherOneCLauncher` в Linux. Подробнее — в разделе «Где хранятся данные».

## Главное окно

**Панель кнопок** (слева направо):
- дерево или список;
- развернуть и свернуть все группы;
- добавить базу или группу;
- изменить выделенную базу или переименовать группу (как F2 и «Изменить…» в контекстном меню). Группа базы в форме выбирается кнопкой «…» у поля «Группа»: откроется окно с деревом групп и кнопкой «Создать группу…» (корень дерева — «Информационные базы», то есть база без группы; новая группа создаётся внутри выделенной). В поле показывается только своя группа (полный путь — в подсказке), кнопка ✕ очищает поле; «Не выбрана» — база в корне списка;
- удалить;
- переключатель «Все базы» / «Недавние» / «Избранное»;
- обновить списки;
- средства администрирования: инструменты и консоль кластера серверов;
- тема (как в системе, светлая, тёмная);
- настройки.

Справа от кнопок — поле поиска.

**Список баз.** В дереве базы разложены по группам, как в стартере 1С. Сверху — группа «Избранное». Колонки:
- Наименование;
- Платформа, на которой база запустится (оранжевым, если нужной версии нет);
- Режим запуска;
- Дата последнего запуска;
- В колонке наименования, у её правого края, — кнопки «1С: Предприятие», «Конфигуратор» и «Запустить с параметрами»: появляются у строки под указателем мыши и у выделенной (отключаются в настройках).

Ширину колонок «Платформа», «Режим запуска» и «Последний запуск» можно менять: потяните границу слева от колонки в заголовке (она видна при наведении на заголовок). Наименование занимает оставшееся место. Ширина запоминается; двойной щелчок по границе возвращает ширину по умолчанию.

Порядок в дереве — по наименованию или свой. Переключается щелчком по заголовку «Наименование». Если переставить базы, пока включён порядок по наименованию, лаунчер запишет этот порядок в список и переключится на свой. Одну группу можно упорядочить по наименованию из контекстного меню.

**Все базы, недавние, избранное.** Что показать, выбирается переключателем на панели кнопок:
- «Все базы» (значок базы) — полный список, деревом или списком;
- «Недавние» (часы) — только базы, которые запускались из лаунчера, свежие сверху;
- «Избранное» (звезда) — только избранные базы, по наименованию; база, убранная из избранного, сразу исчезает из списка.

В недавних и избранном поиск ищет только среди них, а добавлять, удалять и переставлять базы нельзя.

**Поиск** начинается с любого набора текста, даже если фокус в списке. Ищет:
- по имени, серверу, пути и адресу базы;
- в любой раскладке (`,e[ufknthbz` найдёт «Бухгалтерия»);
- по начальным буквам слов («зуп» найдёт «Зарплата и управление персоналом»).

Сначала идут более точные совпадения. Esc очищает поиск.

**Справа — кнопки запуска и свойства базы.**

Кнопки «1С: Предприятие» и «Конфигуратор» (их можно скрыть в настройках). У каждой справа прикреплена кнопка «Запустить с параметрами» именно в этом режиме. Под ними — «Стартер 1С»: запускает стандартный стартер 1С (1cestart) с его собственным списком баз, выбранная база для него не нужна. Стартер ищется в C:\Program Files\1cv8\common и C:\Program Files (x86)\1cv8\common (в Linux — в /opt/1cv8/common и /opt/1C/v8.3/common). Если найдены оба, лаунчер спрашивает, какой запустить.

Под кнопками — «Свойства информационной базы»: имя, кнопка «В избранное» и три группы свойств:
1. Тип, Клиент, Платформа, Параметры, Пользователь, Подключение. У подключения есть кнопки «Копировать строку подключения» и «Открыть каталог базы» (для файловых баз).
2. Источник (в каком списке найдена база) и Группа.
3. Кэш, Доступность, Последний запуск, Запусков.

Панель свойств скрывается кнопкой в правом углу строки состояния или флажком в настройках. Ширина правой колонки меняется перетаскиванием разделителя.

**Строка состояния** (слева направо):
- адрес выделенной базы и кнопка его копирования;
- сообщения лаунчера;
- число недоступных баз (⚠);
- размер кэша (кнопка открывает окно «Кэш баз»);
- число найденных платформ.

## Запуск баз

- **1С: Предприятие** — двойной щелчок, Enter или F3. **Конфигуратор** — F4 или контекстное меню. Веб-базы открываются в браузере.
- **Запустить с параметрами** (F6) — разовый запуск. Можно указать параметры командной строки, пользователя, клиент и версию платформы. Версию можно запомнить для базы. Если окно открыто кнопкой, прикреплённой к «1С: Предприятие» или «Конфигуратору», режим уже выбран: вместо этих двух кнопок в окне одна — «Продолжить» (Enter). Из F6, контекстного меню и кнопки в строке списка режим выбирается в окне.
- **Версия платформы** берётся из свойства `Version` базы. Если его нет — из версии по умолчанию стартера 1С. Если нет и её — самая новая установленная. Если нужной версии нет, лаунчер не запускает другую молча, а спрашивает и предлагает ближайшую из той же ветки.
- **Разрядность** задаётся в свойствах базы, поле «Разрядность»:
  - только 32 или только 64 бита;
  - предпочтительно 32 или 64;
  - автоматически.

  Хранится так же, как у стартера 1С. Если не задана, берётся разрядность из настроек лаунчера.
- **Параметры запуска** есть у базы и у группы; параметры группы действуют на все базы в ней. При запуске они применяются по порядку:
  1. параметры из списка баз (`AdditionalParameters`);
  2. параметры групп, от верхней к вложенной;
  3. параметры базы;
  4. разовые параметры.
- **Пользователь и пароль** базы задаются в «Параметрах запуска…». Пароль хранится в хранилище паролей ОС: в Windows — «Диспетчер учётных данных», в Linux — связка ключей. В логах и на экране он скрыт. Если пароль прочитать не удалось, 1С спросит его сама.

## Свои шаблоны параметров

В окне «Параметры запуска» можно вставить параметр из списка шаблонов. Список настраивается в окне «Настройки» на вкладке «Шаблоны параметров».

Вкладка показывает таблицу известных параметров командной строки 1С с описаниями: сверху свои (с меткой «свой»), ниже встроенные.

Параметры на вкладке пишутся без «/». Лаунчер подставляет его сам, когда шаблон выбирают для запуска: `N Иванов` превратится в `/N Иванов`.

- **Добавить:** введите параметр и описание в поля под таблицей и нажмите «Добавить» или Enter.
- **Изменить:** выделите свой параметр и нажмите «Изменить», F2 или сделайте двойной щелчок. Enter применяет изменение, Esc отменяет.
- **Удалить:** кнопка «Удалить» или Del. Встроенные параметры не изменяются и не удаляются.
- Изменения сохраняются кнопкой «Сохранить» окна настроек вместе с остальными настройками; пока они не сохранены, у вкладки стоит «*».

## Список баз

Лаунчер читает те же файлы, что и стартер 1С:
- личный список `ibases.v8i`;
- общие списки из `1cestart.cfg`;
- списки с веб-сервиса.

Если общий список или веб-сервис недоступен, его базы показываются из последней удачной копии с датой.

Правится только личный список. Можно:
- добавлять, изменять, удалять и копировать базы;
- создавать и переименовывать группы;
- менять порядок, в том числе перетаскиванием;
- загружать базы из файла `.v8i` (меню кнопки «Добавить») и сохранять ссылку на базу в файл `.v8i` (контекстное меню).

Удаление убирает базу только из списка, сама база остаётся на месте.

### Добавление и создание базы

«Новая база…» сначала спрашивает, что сделать (как штатный стартер 1С):
- **Добавить в список существующую базу** — в каталоге, на сервере 1С:Предприятия или на веб-сервере. В поле «Строка подключения» под названием можно вставить, что есть под рукой, — лаунчер сам определит расположение и заполнит остальные поля:
  - строку подключения 1С: `File="C:\Bases\Buh";`, `Srvr="srv:1541";Ref="buh";`, `ws="https://server/buh";` (и строку `Connect=…` из `ibases.v8i`);
  - параметры командной строки: `/F"C:\Bases\Buh"`, `/S"srv:1541\buh"`, `/WS"https://server/buh"`, `/IBConnectionString"…"`;
  - путь к каталогу базы или к файлу `1Cv8.1CD`;
  - адрес из браузера: `https://server/buh/ru_RU/#e1cib/…` или адрес сервиса (`…/odata/…`, `…/hs/…`) — останется адрес публикации `https://server/buh`;
  - сервер и базу, как их показывает стартер: `srv\buh`, `srv:1541\buh`, `tcp://srv:1541/buh`.

  Под полем видно, что определено: каталог, адрес публикации или сервер, порт кластера и имя базы в кластере. Пустое название заполняется именем каталога, базы или публикации. Пользователь и пароль (`Usr`, `Pwd`) из строки не сохраняются, другие ключи (например, `wsn`) — сохраняются;
- **Создать новую базу из шаблона** — шаблон выбирается отдельным шагом. Шаблоны берутся из каталога шаблонов 1С (`%APPDATA%\1C\1cv8\tmplts` и каталоги `ConfigurationTemplatesLocation` из `1cestart.cfg`, по манифестам `1cv8.mft`) и показываются деревом: конфигурация, внутри — её версии, новые сверху. Есть поиск по имени конфигурации и версии (несколько слов — все должны встретиться). Кнопка «Выбрать файл…» берёт любой `.cf` или `.dt`. Если в версии шаблона есть и конфигурация (`.cf`), и демонстрационная база (`.dt`), можно выбрать, что создать: базу только с конфигурацией (без данных) или демонстрационную базу с данными;
- **Создать базу без конфигурации** — для разработки новой конфигурации или загрузки выгруженной ранее базы.

Новую базу можно создать только в каталоге (на этом компьютере или в локальной сети) или на сервере 1С:Предприятия. Для файловой базы указываются каталог (пустой или несуществующий) и язык (страна). Для серверной — те же параметры, что у штатного стартера: кластер серверов, имя базы в кластере, защищённое соединение, тип СУБД, сервер и имя базы данных, пользователь и пароль базы данных, смещение дат (только MS SQL Server), «Создать базу данных в случае её отсутствия», язык (страна), «Установить блокировку регламентных заданий», «Запретить локальное распознавание речи».

Базу создаёт платформа: `1cv8 CREATEINFOBASE` на выбранной версии (поле «Создать на платформе»; для серверной базы — версия, как у сервера). Лаунчер ждёт завершения. Если платформа сообщила об ошибке, её текст показывается в форме, и параметры можно поправить. Перед созданием лаунчер проверяет, что базы с таким же названием (без учёта регистра) нет ни в одном из загруженных списков. Созданная база добавляется в личный список с указанным названием и группой. Пароль базы данных никуда не сохраняется, а в журнале лаунчера скрыт.

Лаунчер не теряет чужих изменений в файле. Если стартер 1С или другая программа изменили список, он перечитывается автоматически. При первой записи за сеанс сохраняется резервная копия `ibases.v8i.bak`.

## Средства администрирования

Кнопка с двумя стойками сервера на панели открывает окно «Средства администрирования». В нём один список из трёх частей, разделённых чертой:
1. **Инструменты** из настроек (вкладка «Средства администрирования», таблица «Инструменты») — в том же порядке. В строке значок инструмента и его имя; строка запуска не показывается. Если значок не задан, показывается подобранный сам или значок по умолчанию (веб-страница у сервиса, «App» у программы). Сервис открывается в браузере по умолчанию, программа запускается со своими параметрами (в Windows — через оболочку, поэтому открываются и оснастки `.msc`, и ярлыки). Если инструментов нет, внизу окна подсказка, где их добавить.
2. **Зарегистрированные консоли кластера серверов** с меткой «зарегистрирована» — их может быть две: 64- и 32-разрядная, от разных платформ. Первая из них выбрана по умолчанию.
3. **Группа «Доступные к регистрации»** с числом версий — по умолчанию свёрнута. Раскрывается щелчком по заголовку, Enter или кнопкой «Развернуть». В ней — установленные платформы, в которых есть компонент администрирования серверов (`radmin.dll`), 64- и 32-разрядные, в том числе установленные без клиента 1С (только сервер и администрирование). Новые сверху, при одной версии 64-разрядная первой.

Выберите строку и нажмите «Запустить» («Открыть» для инструмента), Enter или сделайте двойной щелчок:
- для зарегистрированной версии сразу открывается консоль (оснастка MMC `1CV8 Servers*.msc` из каталога `1cv8\common`, у 32-разрядной — в 32-разрядном MMC);
- для другой версии лаунчер сначала регистрирует её `radmin.dll` (`regsvr32`), и Windows запрашивает права администратора. Если в правах отказать, окно остаётся открытым с сообщением.

Как определяются зарегистрированные версии: лаунчер перебирает оснастки MMC, зарегистрированные в Windows (64- и 32-разрядные — в разных разделах реестра и под разными COM-классами), и берёт те, чей компонент — `radmin.dll`. Поэтому видны обе консоли, если зарегистрированы обе. Регистрации прежних версий платформы остаются в реестре под своими классами, поэтому действующей считается только та, чей класс указан в файле консоли этой разрядности в `1cv8\common` (`1CV8 Servers.msc` или `1CV8 Servers (x86-64).msc`) — её и откроет MMC. Класс может быть зарегистрирован дважды: для всего компьютера и для текущего пользователя, с разными версиями. У администратора MMC запускается с повышенными правами и использует только регистрацию для компьютера — её лаунчер и считает действующей; у обычного пользователя действует его собственная. Что нашлось, пишется в лог строкой «Консоль кластера: в реестре — …», недействующие регистрации помечены «(не действует)». Если зарегистрированная платформа установлена в нестандартный каталог, её версия берётся из пути к `radmin.dll`. Файл оснастки ищется в `common` своей установки, а если его там нет — в `1cv8\common` обеих Program Files.

Консоль кластера есть только в Windows. Инструменты работают и тогда, когда ни одной версии с консолью нет.

Отдельной настройки «Адрес сервиса ПУСК» больше нет: заданный в прежней версии адрес при первом запуске переносится в таблицу «Инструменты» первой строкой — «Панель управления сервисами и компонентами» со значком «ПУСК».

## Кэш баз

В свойствах базы показан размер её кэша. Окно «Кэш баз» открывается кнопкой с размером кэша в строке состояния. В нём:
- кэш всех баз;
- кэш баз, которых уже нет в списках;
- очистка выбранного;
- сортировка щелчком по заголовкам «База» (по имени) и «Кэш» (по размеру, вместе с настройками); повторный щелчок меняет направление. По умолчанию — сначала самые большие.

Кэш удаляется насовсем, без корзины, после вопроса «Удалить кэш?». «Очистить кэш» и «Очистить кэш и запустить» есть и в контекстном меню базы. Там же — подменю «Открыть каталог кэша»: «Программный кэш» (Local) и «Пользовательский кэш» (настройки пользователя, Roaming); пункт недоступен, если такого каталога у базы нет.

Кэш открытой базы не удаляется. Перед очисткой лаунчер смотрит запущенные процессы 1С (`1cv8`, `1cv8c`) **только текущего пользователя** и их командные строки. Если в командной строке адрес очищаемой базы (`/S`, `/F`, `/WS`, `/IBConnectionString`) или её имя (`/IBName`), появляется сообщение «Очистка кэша невозможна: база используется» с номером процесса. В окне «Кэш баз» такие базы пропускаются, кэш остальных выбранных удаляется. «Очистить кэш и запустить» в этом случае базу не запускает: она уже открыта. Каталог с открытыми файлами тоже не удаляется — это дополнительная страховка.

## Проверка доступности баз

Лаунчер в фоне проверяет, можно ли дотянуться до каждой базы. Цель — заранее увидеть, что каталог базы пропал или сервер выключен, а не ждать ошибки от 1С. Проверка включена по умолчанию и выключается флажком «Проверять доступность баз» в настройках.

### Когда проверяется

- после каждой полной загрузки списков: при открытии лаунчера, по кнопке «Обновить» (F5) и когда списки перечитываются из-за изменений в `1cestart.cfg`;
- сразу после включения флажка в настройках.

Проверка идёт в фоне и не мешает работать: список показывается сразу, отметки появляются, когда проверка закончится.

База, которую только что добавили или изменили в лаунчере, проверяется при следующей полной загрузке (F5).

Результаты не сохраняются между запусками лаунчера.

### Что проверяется

Способ зависит от типа подключения базы:

| Тип базы | Строка подключения | Что делает лаунчер | Когда база считается доступной |
|---|---|---|---|
| Файловая | `File="C:\Bases\Buh"` | проверяет, что каталог базы существует | каталог найден |
| Клиент-серверная | `Srvr="srv1c";Ref="buh"` | открывает TCP-соединение с менеджером кластера 1С и сразу закрывает его | сервер принял соединение |
| Веб-база | `ws="https://web/buh"` | открывает TCP-соединение с веб-сервером и сразу закрывает его | веб-сервер принял соединение |

Как определяется адрес:
- **Порт сервера 1С.** Если он указан в `Srvr` (`srv1c:1641`), берётся он, иначе стандартный порт менеджера кластера 1541. Понимаются записи вида `tcp://srv1c:1541` и IPv6 в квадратных скобках (`[::1]:1541`). Если в `Srvr` перечислено несколько серверов через запятую или точку с запятой, проверяется первый.
- **Порт веб-сервера** берётся из адреса, а если его там нет — стандартный: 80 для `http`, 443 для `https`.

Чего проверка **не** делает — это цена быстроты и отсутствия побочных эффектов:
- не открывает базу, не входит в неё и не проверяет имя пользователя и пароль;
- у файловой базы не проверяет файл `1Cv8.1CD` и права на запись. Проверяется только, что каталог виден;
- у серверной базы не проверяет, что в кластере есть база с именем из `Ref`, и не проверяет рабочие процессы и их порты. Проверяется только, что менеджер кластера принимает соединения;
- у веб-базы не отправляет HTTP-запрос. Проверяется только, что веб-сервер принимает соединения, а не что публикация по этому пути существует.

Поэтому отметка «доступна» означает только, что адрес отвечает. Отметка «недоступна» почти наверняка означает, что запуск не удастся: каталога нет, сервер выключен, адрес неверен или соединение закрыто сетевым экраном.

### Ограничения по времени и нагрузке

- На каждую проверку даётся **3 секунды**. Не ответил за это время — считается недоступным («нет ответа за 3 с»). Это защищает и от «зависших» сетевых путей, на которых проверка каталога может ждать очень долго.
- Одновременно выполняется не больше **8** проверок.
- Одинаковые адреса проверяются **один раз**. Если на одном сервере 1С двадцать баз, к менеджеру кластера будет одно подключение. Одна и та же база из нескольких списков тоже проверяется один раз.
- Если строку подключения не удалось разобрать (нет пути, сервера или адреса), база не проверяется и помечается «проверить нельзя».

### Как показывается результат

- В дереве и списке перед именем недоступной базы стоит ⚠. Подсказка к значку объясняет причину.
- В свойствах базы, строка «Доступность», показано одно из значений:
  - «доступна (srv1c:1541 отвечает)»;
  - «недоступна: каталог базы не найден: …»;
  - «недоступна: srv1c: нет ответа за 3 с»;
  - «проверить нельзя»;
  - «не проверялась».
- В строке состояния — «⚠ недоступно: N», если такие базы есть.
- В лог пишется итог: сколько баз проверено и сколько не отвечает.

Отметка ничего не запрещает: недоступную базу можно запустить, и 1С сама сообщит, что не так. Если выключить проверку, отметки сразу снимаются, и лаунчер перестаёт обращаться к сети ради неё.

## Настройки

Кнопка с шестерёнкой открывает окно «Настройки». Вкладки расположены слева.

**Общие** — поведение лаунчера:

| Настройка | Что делает |
|---|---|
| После запуска базы | ничего не делать, свернуть окно или закрыть лаунчер |
| Сворачивать в трей | свёрнутое окно убирается с панели задач. Значок лаунчера — в области уведомлений: щелчок возвращает окно, в меню есть «Открыть лаунчер» и «Выход» |
| Запретить повторный запуск | второй запуск лаунчера не открывает новое окно, а показывает уже работающее, в том числе из трея. Действует со следующего запуска |
| Файловые базы с клиентом «Автоматически» открывать в толстом клиенте | для баз, у которых клиент не выбран явно |
| Проверять доступность баз | фоновая проверка (см. выше) |

**Внешний вид:**

| Настройка | Что делает |
|---|---|
| Тема | как в системе, светлая или тёмная. Кнопка темы на панели переключает её сразу |
| Стиль значков | «Стиль 1» (по умолчанию) — значки цветным контуром, «Стиль 2» — знак на цветной плашке. Кнопки у обоих стилей одинаковые: панель плоская — без фона (фон при наведении), значки крупнее, группы разделены чертой, «Все базы / Недавние / Избранное» — тумблер; остальные кнопки во всех окнах — со скруглением и лёгкой заливкой вместо рамки 
| Показывать свойства информационной базы | показать или скрыть панель свойств (то же — кнопка в правом углу строки состояния) |
| Кнопки запуска 1С справа от списка баз | показать или скрыть кнопки «1С: Предприятие» и «Конфигуратор» над свойствами. Если скрыты и они, и свойства, правая панель убирается и список занимает всю ширину |
| Кнопки запуска 1С в строках списка баз | маленькие кнопки «1С: Предприятие», «Конфигуратор» и «Запустить с параметрами» в колонке наименования — у строки под указателем мыши и у выделенной |
| Место кнопок в строке | «Справа, у края колонки наименования» (по умолчанию) или «Слева от наименования». Слева — одна кнопка ▶ в каждой строке, видна всегда; щелчок по ней открывает меню: «1С: Предприятие», «Конфигуратор», «Запустить с параметрами…» |
| Подсвечивать запущенные базы | зелёная точка справа от наименования у баз, открытых в 1С текущим пользователем — из лаунчера, стартером 1С или ярлыком; в подсказке — в каких клиентах. Раз в 3 секунды читаются процессы `1cv8`/`1cv8c` и их командные строки (адрес базы или `/IBName`); база, выбранная в окне запуска самой 1С, не видна. По умолчанию включено |
| Список баз в две строки | в первой строке — наименование базы и кнопки запуска, во второй — платформа, режим запуска и дата последнего запуска; колонок справа нет. По умолчанию выключено |
| Чередование цвета строк | каждая вторая видимая строка списка баз — на лёгкой подложке (в дереве считаются только показанные строки). Значения: «Не использовать», «Едва заметно», «Умеренно» (по умолчанию), «Заметно» |

**Горячие клавиши** — сочетания для команд, у которых они есть (см. «Клавиши» ниже):
- чтобы переназначить, щёлкните сочетание и нажмите новое; Esc отменяет ввод;
- кнопка со стрелкой возвращает сочетание по умолчанию, ✕ снимает его, «Всё по умолчанию» сбрасывает все;
- без Ctrl или Alt можно назначить только F1–F24 (и Del — командам списка), чтобы клавиши не мешали набору в поиске;
- занятое другой командой сочетание не назначается — окно скажет, какой командой оно занято.

**Шаблоны параметров** — встроенные и свои параметры командной строки (см. «Свои шаблоны параметров» выше).

**Средства администрирования** — таблица «Инструменты»: веб-сервисы и программы для администрирования. Они показываются первыми в окне «Средства администрирования» (кнопка с двумя стойками сервера). У инструмента три колонки:

| Колонка | Что в ней |
|---|---|
| Имя | название инструмента; имена не повторяются |
| Строка запуска | адрес веб-страницы сервиса (`http://`, `https://`) или путь к программе. Путь с пробелами — в кавычках, параметры — после него: `"C:\Program Files\Tool\tool.exe" -x`. Можно и без кавычек: `mmc.exe compmgmt.msc`. Имя без каталога (`notepad`) ищется по PATH, переменные окружения (`%windir%`) раскрываются. Кнопка «…» выбирает программу |
| Значок | по умолчанию подбирается сам: у программы — её значок (как в Проводнике), у сервиса — значок сайта из заголовка страницы (`<link rel="icon">`, иначе `/favicon.ico`). Если значок не нашёлся — у сервиса значок веб-страницы, у программы — плашка «App» |

Кнопка значка открывает меню: «Автоматически», встроенные значки лаунчера (ПУСК, консоль кластера, 1С: Предприятие, Конфигуратор, стартер 1С, лаунчер, веб-страница, App) и «Загрузить свой…» — картинка PNG, ICO, JPEG, BMP, GIF или WebP. Свой значок копируется в каталог лаунчера, исходный файл можно удалить.

Инструменты добавляются и изменяются в полях под таблицей (Enter — добавить или применить, Esc — отменить изменение), F2 или двойной щелчок — изменить, Del — удалить, стрелки — порядок.

Изменения копятся, пока не нажата «Сохранить». Пока есть несохранённые изменения, в заголовке окна и у изменённой вкладки стоит «*», а кнопка «Сохранить» доступна. «Отменить» закрывает окно без изменений.

Внизу окна — «О программе…»: версия, автор, сведения о среде.

## Клавиши

Сочетания по умолчанию. Их можно переназначить в «Настройки» → «Горячие клавиши»; Enter, двойной щелчок, Esc, Ins и ↓ из поиска не переназначаются.

| Клавиши | Действие |
|---|---|
| набор текста | поиск |
| F3, Enter, двойной щелчок | запуск в режиме 1С: Предприятие |
| F4 | Конфигуратор |
| F6 | запустить с параметрами |
| ↓ | из поиска — к списку |
| Esc, Ctrl+Q | очистить поиск |
| Ctrl+F | к полю поиска |
| Ctrl+D | в избранное / из избранного |
| F5 | перечитать списки и платформы |
| Ctrl+N, Ins | новая база |
| Ctrl+Shift+N | новая группа |
| F2 | изменить базу, переименовать группу |
| Del | удалить из списка (сама база не удаляется) |
| Alt+↑, Alt+↓ | порядок в группе |

В Windows у значка лаунчера на панели задач есть список переходов (правый щелчок) с пятью последними базами. Щелчок по базе запускает её, даже если лаунчер закрыт.

## Где хранятся данные

| Что | Где |
|---|---|
| Списки баз | там же, где у стартера 1С: `%APPDATA%\1C\1CEStart\ibases.v8i` и `1cestart.cfg` |
| Настройки лаунчера: избранное, история, параметры запуска, вид окна | `<каталог настроек>\settings.json` |
| Копии общих списков и списков с веб-сервиса | `<каталог настроек>\list-cache` |
| Лог | `<каталог настроек>\logs\launcher-<дата>.log`, хранится 14 дней |
| Пароли | хранилище паролей ОС, в `settings.json` их нет |
| Свои значки средств администрирования | `<каталог настроек>\tool-icons`; неиспользуемые удаляются при сохранении настроек |

`<каталог настроек>`: `%APPDATA%\YetAnotherOneCLauncher` в Windows и `~/.config/YetAnotherOneCLauncher` в Linux.

Лаунчер хранит свои настройки отдельно и не пишет их в списки баз 1С.
